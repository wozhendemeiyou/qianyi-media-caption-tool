# 芊熠智能打标工作台 v3.6.1

v3.6.1 是 Windows 应用内更新热修复版，解决更新下载完成后没有覆盖旧程序、也没有自动重启的问题。

## 重要升级说明

v3.5 与 2026年8月15日发布的初始 v3.6 自身包含旧更新器缺陷，因此可能表现为：

1. 新版本下载和 SHA-256 校验均已完成；
2. 界面提示准备安装；
3. 旧程序没有被覆盖，新程序也没有重新启动。

旧更新器无法通过远程替换下载资产来自我修复。请从本页面手动下载并运行一次 v3.6.1 EXE。用户项目、提示词、平台设置和使用 Windows DPAPI 加密保存的 API Key 均位于本地应用数据目录，不会因替换 EXE 被删除。

从 v3.6.1 开始，后续版本可恢复软件内下载、覆盖安装和自动重启。

## 修复内容

- 移除导致 PowerShell 更新脚本立即退出的 `DETACHED_PROCESS` 标志；
- 改用可靠的隐藏更新子进程，并在主程序退出前确认更新器仍在运行；
- 先将新程序复制到安装目录的暂存文件，再进行 SHA-256 校验和原子式替换；
- 覆盖完成后再次校验已安装 EXE，并以原安装目录作为工作目录重新启动；
- 新增 `update-install.log`，安装失败时保留明确错误信息；
- 新增真实 Windows 父进程退出测试，验证主程序结束后更新器仍会完成覆盖。
