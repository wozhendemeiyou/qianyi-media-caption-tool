# 芊熠智能打标工作台 v3.6

v3.6 聚焦平台接入、模型供应商配置和设置界面的可用性，新增自定义 OpenAI 兼容接口，并继续完善应用内更新体验。

![v3.6 主工作区](https://raw.githubusercontent.com/wozhendemeiyou/qianyi-media-caption-tool/v3.6/docs/images/workbench.png)

## 本版重点

- 新增“自定义 OpenAI 兼容接口”，用户可填写 Base URL、模型 ID 与可选 API Key；
- 内置供应商不再显示 Base URL，只需配置 API Key；
- 供应商菜单加入品牌图标，固定选择框尺寸，切换长短名称时不再跳动；
- 更新 OpenAI、Google Gemini、Kimi、千问与 SiliconFlow 的近期视觉模型候选；
- MiniMax M3 归入火山引擎 Coding Plan，不再保留重复供应商入口；
- API 与本地模型分区并互斥置灰，避免同时启用造成配置歧义；
- 精简平台设置，移除重复的输出偏好和后端互斥说明；
- 选择本地模型时提示并发会增加显存占用，推荐并发数为 1；
- 修复自定义接口展开后窗口高度未同步更新、底部内容显示不全的问题；
- 自动更新开关迁移至“系统说明 → 版本信息”，发现新版本后仍可在软件内直接下载安装覆盖。

![v3.6 平台设置](https://raw.githubusercontent.com/wozhendemeiyou/qianyi-media-caption-tool/v3.6/docs/images/platform-settings.png)

## 自定义接口配置

1. 在“平台设置”中选择“外部 API”；
2. API 平台选择“自定义 OpenAI 兼容接口”；
3. 填写模型 ID 和兼容 Base URL，例如 `https://host/v1`；
4. 接口需要鉴权时填写 API Key，不需要鉴权时可以留空；
5. 点击“测试连接”，确认连接状态后保存。

内置供应商的公开路由由程序管理，不向用户显示 Base URL；只有自定义接口会展开 Base URL 输入项。

## 公开发布隐私状态

本仓库和 Release 包已经清空并排除：

- 所有 API Key、令牌和认证头；
- 所有用户提示词模板与用户要求；
- 自定义 API 地址和用户模型配置；
- 最近项目、数据集路径、本地模型目录和运行日志；
- `settings.json`、`config.json`、`credentials*.bin`。

程序内保留的服务商域名、公开 Base URL 和模型 ID 只是联网功能所需的公开路由，不包含账号凭据。
