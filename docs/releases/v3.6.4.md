# 芊熠智能打标工作台 v3.6.4

v3.6.4 集中修复 LM Studio 视觉模型加载、思考输出、显存管理和 Hugging Face 本地推理稳定性。

## 更新内容

- LM Studio 新增“低显存安全（推荐）”“纯 CPU（最稳定）”和“沿用 LM Studio 预设”三种加载策略。
- 推荐策略通过本机 `lms` CLI 明确应用 10% GPU Offload、8192 上下文、并行 1 并关闭 MTP，不再复用旧的高显存加载预设。
- 模型列表会读取并显示当前实例的真实上下文、并行数、MTP 状态、推理能力与模型体积。
- 开启“移除思考标签”后，请求会发送 `reasoning_effort: none`，在生成前关闭思考，而不是生成后仅删除标签。
- LM Studio 打标输出安全上限提升为 768 tokens；用户选择保留思考时使用 1536 tokens。
- 图片请求最长边调整为 1280 像素，减少视觉 tokens、显存压力和首段处理时间，同时保留打标所需细节。
- `HTTP 400 {"error":"terminated"}`、显存不足、服务未启动、思考预算耗尽和截断输出均改为明确中文提示，异常结果不会写入 TXT。
- Hugging Face 大模型使用 Accelerate 自动设备分配与低内存加载，支持 GPU/CPU 安全拆分。
- Hugging Face 单实例生成增加互斥保护，避免多个线程同时争抢 KV Cache；补充编码器—解码器输出兼容、显存错误翻译及任务结束后的缓存释放。
- 设置架构升级为 13，LM Studio 加载策略会持久保存，异常旧配置会自动恢复为安全默认值。

## 真机验证

- 使用 RTX 4060 Laptop 8 GB 与 Qwen3.8-27B IQ4_XS 对此前失败的同一图片进行测试；
- 旧配置在图片处理约 1% 时因 Vulkan 显存分配失败返回 `terminated`；
- 低显存安全策略下完整生成中文标注，不再发生模型进程退出；
- 图片输入由 2842 tokens 降至 1125 tokens；
- 思考 tokens 由 172/256 降为 0；
- 单图耗时由约 239.7 秒降低至约 99.9 秒。
