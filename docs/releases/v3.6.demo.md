# 芊熠智能打标工作台 v3.6.demo

这是 3.6.6 稳定版之后的现代 GUI 架构演示版本，不替换稳定版 Release。

## 迁移内容

- PySide6 三列工作区与 token 化日光/夜光主题；
- 平台连接测试、LM Studio 模型刷新/加载/卸载；
- llama.cpp 上下文长度与 GPU 层数控件；
- 批量/单次反推、结果保存、JSONL/CSV 导出、运行日志和更新检查；
- 现有核心、模型路由和设置存储全部复用；
- 经典 Tk 工作台继续作为完整功能回退入口。

## 启动

```powershell
.\.venv312\Scripts\python.exe -m pip install -r requirements-qt.txt
.\.venv312\Scripts\python.exe media_caption_qt.py
```

`3.6.demo` 暂不创建正式 GitHub Release，待 Qt 版完成真机回归后再决定是否成为默认入口。
