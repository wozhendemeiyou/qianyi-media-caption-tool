# 芊熠智能打标工作台 v3.6.5

v3.6.5 将原生 llama.cpp GGUF 纳入本地运行方式，并继续保留 Hugging Face 与 LM Studio 的现有路径。

## 更新内容

- 新增“llama.cpp 原生 GGUF”平台设置，可选择 `llama-server.exe`、GGUF 主模型和视觉 `mmproj*.gguf`。
- 选择主模型后，同目录只有一个 `mmproj` 文件时自动关联，减少手工配置错误。
- 任务开始时自动分配本地端口并启动 llama-server；任务完成、停止、取消、启动失败或异常退出时自动清理进程。
- 支持上下文长度、GPU 层数和模型别名设置，服务器日志写入本机应用数据目录的 `logs/llama-cpp/`。
- 设置架构升级为 14，新增 GGUF 配置持久化，同时兼容旧的 Hugging Face 与 LM Studio 配置。
- 保留独立单次反推、音视频片段编辑、并发提示、主题切换和应用内更新能力。

## 使用前准备

请准备与模型匹配的 Windows llama.cpp 发行包，并在“平台设置 → 本地模型 → llama.cpp 原生 GGUF”中选择 `llama-server.exe`、主模型和 `mmproj`。显存不足时先降低 GPU 层数，再降低上下文长度；并发建议从 1 开始。

## 验证

- Python 语法编译检查通过；
- 应用 smoke test 通过；
- GUI、Worker 和核心回归测试通过；
- 发布前安全扫描继续确保仓库不包含 API Key、提示词模板或用户本地配置。

构建 Windows 安装包时使用仓库中的 `MediaCaptionTool-3.6.5.spec`，生成的文件版本资源为 `3.6.5.0`，产品版本为 `3.6.5`。
