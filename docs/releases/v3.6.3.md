# 芊熠智能打标工作台 v3.6.3

v3.6.3 汇总 Windows 产品信息、更新器兼容、MTP 与思考标签控制，以及全局主题一致性修复。

## 更新内容

- 公司名：`芊熠智能`；
- 产品名与文件说明：`芊熠智能打标工作台`；
- 文件版本：`3.6.3.0`；
- 产品版本：`3.6.3`；
- 内部名称：`QianyiMediaCaptionTool`；
- 原始文件名：`Qianyi-MediaCaptionTool.exe`；
- 版权：`Copyright © 2026 芊熠智能. All rights reserved.`。
- 修复旧版点击立即更新后，新版沿用旧 `_MEI` 临时目录而无法加载 `python312.dll` 的问题；更新器会清理 PyInstaller 继承环境，并等待旧进程彻底退出后再覆盖重启。
- “API 平台与模型”标题右侧新增“启用 MTP”和“移除思考标签”圆角滑块；兼容本地模型可使用原生 MTP 加速，不兼容时自动回退。
- 思考标签清理默认开启，兼容请求会关闭思考输出，并从最终结果中移除常见思考区块，避免污染训练 TXT。
- 修复下拉框弹层首次在夜光模式打开后，切换日光模式仍残留深绿色背景的问题。
- 全部 10 个下拉框统一刷新背景、文字、选中态、焦点边框和滚动条。
- 菜单、动态平台设置弹窗、原生文本区和圆角开关统一接入主题同步。
- 提升 Tk 选项数据库优先级，并在 Windows 延迟重绘后再次校验当前主题颜色。

这些字段属于 Windows 版本资源，用于明确产品身份和提升文件属性的完整度；它们不等同于 Authenticode 数字签名，也不会伪装可信发布者证书。
