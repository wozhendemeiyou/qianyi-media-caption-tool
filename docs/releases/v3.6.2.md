# 芊熠智能打标工作台 v3.6.2

v3.6.2 是标注结果即时反馈补丁版，解决图片二次打标完成后，当前结果框仍停留在旧内容的问题。

## 修复内容

- 二次打标成功后立即从已落盘 TXT 重新读取，并覆盖刷新当前“标注结果”文本区；
- 同名 sidecar TXT 继续使用原子替换完整重写，不拼接旧内容；
- 结果区新增“正在生成”“结果已更新”“失败并保留原标注”等明确状态；
- 完成后将新结果滚动到顶部，并显示该素材的实际处理耗时；
- 运行日志同步显示每项素材耗时，方便定位平台排队或生成延迟；
- 清理窗口关闭后的图片预览与结果反馈定时回调。

## 升级说明

- v3.6.1 用户可直接使用软件内更新下载、覆盖并自动重启；
- v3.5 与初始 v3.6 的更新器无法自我修复，需要从本页面手动下载并运行最新版 EXE；
- 项目、提示词、平台设置和使用 Windows DPAPI 加密保存的 API Key 不会因替换 EXE 被删除。

## 验证

- GUI 启动与主题自检通过；
- 公开发布安全扫描通过。
