# 芊熠智能打标工作台 v3.5

v3.5 是一次完整的工作区、主题、平台配置、视频后台和更新系统升级。

## 本版重点

- 全新画布优先工作区、语义导航和固定任务栏；
- 包豪斯日光模式与灰绿色夜光模式；
- 全套导航/供应商图标与新版启动页；
- 火山引擎、OpenAI、Google、Kimi、千问、SiliconFlow 多平台路由；
- 可折叠高级采样参数和右侧独立滚动区；
- 视频媒体 Worker、FFprobe 预检、FFmpeg 抽帧/音频接口；
- 系统说明、GitHub 更新检查、应用内下载覆盖安装；
- 自动备份、脱敏诊断和凭据隔离；
- 修复主题残留、启动闪屏、白色边框、滚轮误改参数和 Seed 截断；
- 保存预设使用全新主题化中文模态弹窗。

## 公开发布隐私状态

本仓库和 Release 包已经清空并排除：

- 所有 API Key、令牌和认证头；
- 所有用户提示词模板与用户要求；
- 自定义 API 地址和用户模型配置；
- 最近项目、数据集路径、本地模型目录和运行日志；
- `settings.json`、`config.json`、`credentials*.bin`。

程序内保留的服务商域名、公开 Base URL 和模型 ID 只是联网功能所需的公开路由，不包含账号凭据。

## 首次使用

1. 在项目中心添加媒体目录；
2. 在平台设置中填写自己的 API Key，或选择本地模型；
3. 在提示词页自行编写或导入系统提示词模板；
4. 用少量素材测试输出、采样参数和计费路径；
5. 再开始批量任务。
